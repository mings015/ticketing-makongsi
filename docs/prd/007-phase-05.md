# PHASE 1 — MOBILE MVP

## Overview

Mobile application berfungsi sebagai aplikasi operasional ticketing untuk karyawan dan tim support.

Fokus utama fase ini adalah:

- Login
- Dashboard
- Ticket List
- Ticket Detail
- Create Ticket
- Comment Ticket
- Profile

Mobile tidak digunakan untuk konfigurasi sistem, reporting, audit log, SLA management, maupun user management.

Semua konfigurasi administratif tetap dilakukan melalui web application.

---

# Objectives

## Business Objectives

- Memudahkan pelaporan issue melalui smartphone
- Memudahkan monitoring status ticket
- Mempercepat komunikasi antara requester dan support
- Memungkinkan support melakukan update ticket saat berada di lapangan

---

## Technical Objectives

- Fast and responsive
- Role-based access
- Secure authentication
- Offline-friendly architecture
- Maintainable codebase

# MODULE 001 — AUTHENTICATION

## Goal

Memastikan hanya pengguna yang sah dapat mengakses aplikasi.

---

## Features

### Login

Fields

- Email
- Password

---

### Auto Login

Jika token masih valid:

- langsung masuk dashboard

---

### Logout

Menghapus:

- Access Token
- Refresh Token
- Local User Session

---

### Session Persistence

Token disimpan menggunakan:

Flutter Secure Storage

---

## Business Rules

- User non aktif tidak dapat login
- User tanpa role tidak dapat login

---

## Acceptance Criteria

- Login berhasil dengan credential valid
- Login gagal dengan credential salah
- Session tetap aktif setelah aplikasi ditutup
