# PHASE 4 — GOVERNANCE, REPORTING & ADMINISTRATION

## Overview

Phase ini berfokus pada:

- Monitoring performa layanan
- Audit dan compliance
- Pelaporan operasional

Setelah fase ini selesai, aplikasi ticketing telah memiliki kemampuan enterprise-grade untuk kebutuhan monitoring, audit, dan pengambilan keputusan manajemen.

---

# MODULE 013 — REPORTING & ANALYTICS

## Goal

Menyediakan laporan operasional dan analitik yang dapat digunakan oleh manajemen untuk mengevaluasi performa layanan IT.

---

## Business Objectives

- Mengukur performa tim support
- Mengukur SLA compliance
- Mengidentifikasi masalah yang sering terjadi
- Menjadi dasar pengambilan keputusan

---

## Roles

### Support

Dapat melihat:

- Personal Performance
- Assigned Ticket Statistics

### Team Lead

Dapat melihat:

- Team Performance
- SLA Statistics

### Admin

Dapat melihat:

- Semua laporan operasional

### Super Admin

Dapat mengakses seluruh laporan dan analytics

---

## Report Categories

### Ticket Reports

Menampilkan:

- Total Tickets
- Open Tickets
- Closed Tickets
- Pending Tickets
- Resolved Tickets

---

### SLA Reports

Menampilkan:

- SLA Compliance
- SLA Breach Count
- Average First Response Time
- Average Resolution Time

---

### Category Reports

Menampilkan:

- Ticket by Category
- Ticket by Subcategory
- Most Reported Issue

---

### Department Reports

Menampilkan:

- Ticket by Department
- Department Ranking
- Request Volume

---

### Staff Performance Reports

Menampilkan:

- Ticket Assigned
- Ticket Resolved
- Average Resolution Time
- SLA Compliance Rate

---

### Approval Reports

Menampilkan:

- Total Approvals
- Approved Requests
- Rejected Requests
- Average Approval Time

---

## Analytics Dashboard

### Trends

Menampilkan:

- Daily Tickets
- Weekly Tickets
- Monthly Tickets

---

### Top Issues

Menampilkan:

- Top Categories
- Top Subcategories
- Frequently Repeated Issues

---

### Peak Hours

Menampilkan:

- Jam terbanyak ticket dibuat

---

### Workload Distribution

Menampilkan:

- Ticket per staff
- Ticket per team

---

## Filters

Global Filters

- Date Range
- Department
- Category
- Priority
- Status
- Assignee

---

## Acceptance Criteria

- Semua laporan dapat difilter
- Data dapat di-export
- Statistik dihitung otomatis
- Query laporan tidak mengganggu performa sistem

# MODULE 014 — EXPORT SYSTEM

## Goal

Memungkinkan pengguna mengunduh data dan laporan untuk kebutuhan operasional maupun audit.

---

## Business Objectives

- Mempermudah pelaporan
- Mempermudah audit
- Mendukung kebutuhan manajemen

---

## Export Formats

### Excel

Format:

.xlsx

---

### CSV

Format:

.csv

---

### PDF

Format:

.pdf

---

## Exportable Data

### Ticket Report

Fields:

- Ticket Number
- Title
- Category
- Priority
- Status
- Created By
- Assigned To
- Created At
- Closed At

---

### SLA Report

Fields:

- Ticket Number
- SLA Target
- SLA Actual
- SLA Status

---

### Approval Report

Fields:

- Approval Flow
- Approver
- Action
- Timestamp

---

### Audit Report

Fields:

- Event
- User
- Module
- Timestamp

---

## Business Rules

- Export mengikuti filter aktif
- Export harus mengikuti permission user
- Data sensitif harus disembunyikan sesuai role

---

## Security Rules

- Export dicatat pada audit log
- Download URL memiliki expiry
- Tidak boleh export data tanpa permission

---

## Acceptance Criteria

- Excel dapat dibuka tanpa error
- PDF dapat diunduh
- Export tercatat di audit log

# MODULE 015 — AUDIT LOG

## Goal

Mencatat seluruh aktivitas penting dalam sistem untuk kebutuhan audit, keamanan, dan investigasi.

---

## Business Objectives

- Menyediakan histori aktivitas
- Memenuhi kebutuhan audit
- Meningkatkan keamanan sistem

---

## Logged Activities

### Authentication

- Login
- Logout
- Failed Login
- Password Reset

---

### User Management

- User Created
- User Updated
- User Deactivated
- Role Changed

---

### Ticket Activities

- Ticket Created
- Ticket Updated
- Ticket Assigned
- Status Changed
- Ticket Closed

---

### Approval Activities

- Approved
- Rejected
- Revision Requested

---

### System Activities

- Setting Updated
- SLA Updated
- Category Updated

---

## Audit Log Structure

Fields

- Event ID
- Event Type
- Module
- User ID
- User Name
- Action
- Entity Type
- Entity ID
- Metadata
- IP Address
- User Agent
- Timestamp

---

## Business Rules

- Audit log immutable
- Tidak dapat diedit
- Tidak dapat dihapus oleh user biasa

---

## Search & Filtering

Filter:

- User
- Module
- Event Type
- Date Range

---

## Retention Policy

Minimum:

12 bulan

Recommended:

24 bulan

---

## Acceptance Criteria

- Semua aktivitas penting tercatat
- Audit log dapat dicari
- Audit log tidak dapat dimodifikasi
