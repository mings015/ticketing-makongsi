# Product Vision

## Project Name

Internal Ticketing System

## Purpose

Menyediakan platform terpusat untuk seluruh unit bisnis dalam membuat, memantau, dan mengelola permintaan kepada tim IT.

## Problems

Saat ini request dilakukan melalui:

- WhatsApp
- Chat pribadi
- Telepon
- Email

Akibatnya:

- Request sering terlupakan
- Sulit mengetahui prioritas
- Tidak ada histori pekerjaan
- Sulit membuat laporan

## Goals

### Business Goals

- Semua request terdokumentasi
- SLA dapat diukur
- Progress transparan
- Reporting otomatis

### Technical Goals

- Maintainable
- Secure
- Type-safe
- Testable
- Scalable

## Non Goals

Bukan sistem:

- HRIS
- ERP
- Payroll
- Inventory

## Success Metrics

- 100% request melalui ticket
- SLA compliance > 90%
- Ticket lost = 0
- Average response time < 30 menit
